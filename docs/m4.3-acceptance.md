## 复现与清理

本机使用 `COMPOSE_PROJECT_NAME=nere383`，数据库 `127.0.0.1:15383`、后端 `127.0.0.1:18383`。仓库外 Compose 覆盖仅调整数据库宿主端口与本地后端进程数；启动前检查 lsof 和 Docker 映射，启动后确认 `port db 5432` 为 15383。构建本任务 backend、pi 镜像，浏览器使用本机已有 Chromium，无需再构建浏览器镜像。

```bash
# 先按部署说明启动本任务独立 db、prestart、pi、backend，并核对 db 端口。
export DATABASE_URL=postgresql://postgres:changethis@localhost:15383/app
export POSTGRES_PORT=15383
export PLAYWRIGHT_BASE_URL=http://127.0.0.1:18383
export VITE_API_URL=http://127.0.0.1:18383
export MODEL_TEST_HOST=host.docker.internal
(cd frontend && bunx playwright test tests/m4.3-screenshots.spec.ts --workers=1)
(cd backend && uv run pytest --no-cov -x -q tests/admin_assistant/test_registry.py \
  tests/acceptance/test_m4_3_assistant_import.py)
bash scripts/preflight.sh
```

`MODEL_TEST_HOST` 是本地假模型对 Pi 容器可达的宿主地址，Linux CI 沿用工作流设置的宿主 IP。示例密码仅供独立合成测试库使用。验证结束删除 nere383 容器、卷、网络与项目镜像，执行悬空镜像清理和 `docker builder prune -f --reserved-space 5gb`；不处理 nere236 或其他任务资源。实际清理后的剩余空间及 preflight、自审、PR 检查结果记录在 NERE-383 结果评论中。
