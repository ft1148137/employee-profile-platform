# ADR-0034：管理助手的文件预览与模型摘要

状态：已采纳（NERE-266；NERE-280 扩展）。

名单沿用 `create_import` 保存预览，变更集只引用 `import_id`、`base_revision`，不另存附件，也不增加迁移。`apply_import(commit=False)` 将名单、账号停用、审计和变更集状态交给同一事务提交或回滚。应用前以名单版本和导入状态的快照检查过期。名单导入不能撤销；纠正时重新上传完整名单。

保留既有 `risk(args)` 回调接口；需要读取已保存预览的名单使用 `preview_risk(Session, Principal, args)`，由服务端计算离职人数，两人及以上走既有二次确认。共享账号或部署管理员账号的离职沿用名单服务的阻止规则，不能由模型绕过。不可撤销沿用人员改动的 `undoable=False` 标记。

逐行预览复用网页的结构和组件，作为加密的助手消息保存，遵循原会话归属和保留期，刷新后可以恢复。向模型组装历史时，在字符截断之前将文件预览替换为各类条数和最多 20 条错误的行号、原因。文件全文、逐行差异、姓名、邮箱、部门和列映射不会随文件预览进入模型历史。上传接口本身不调用模型。

NERE-280 在同一上传卡与预览卡中接入批量画像、工作记录和能力词典。三种新文件的预览统一为中文统计与“位置、原因”错误列表，模型历史最多接收 20 条错误。

画像和工作记录的原文件按 Base64 编码，保存在变更集现有的加密 `secrets` 中，不增加附件列和迁移。登记项用 `file_field` 标记这个字段；它与密钥一样从参数快照中排除，只有上传接口能写入，模型参数、安全输入框均不能提供或替换内容。一份变更集最多包含一个文件。重新起草、过期、丢弃和应用都沿用既有密钥清理路径，失效后必须重新上传。

画像预览用保存点隔离内部回滚，确认导入支持 `commit=False`。工作记录的网页与助手复用同一导入服务，沿用同一连接上的同步入队，均随外层事务提交或回滚。两类导入不能撤销，也不绕过既有本人过目与经理确认流程。

词典预览生成 `import_capability_dictionary` 改动，保留 `definitions`、`expected_version`，不保存文件，默认不重新起草画像。它与编辑登记项共用校验、快照和影响计算，但发布时固定 `sync_ai_inference=False`，与网页上传一致，保留已有关闭项（包括文件移除的能力）。撤销仍起草导入登记项，发布上一版内容，不因撤销重新打开 AI 推断。编辑登记项和网页接口不变，不增加可切换行为的模式字段。词典内容不属于个人数据，按既有词典编辑协议进入确认卡和模型上下文，版本冲突与撤销沿用 ADR-0031。
