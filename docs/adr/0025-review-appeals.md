# ADR-0025：申诉以展示状态覆盖正式画像

状态：已接受

拒绝的改动可能没有对应的正式判断。申诉不能成为系统或管理员改正式画像的途径。

申诉按企业、员工和改动项记录。创建时锁定原请求，同项最多一个 open 申诉，并由数据库部分唯一索引兜底。当前画像按能力 key 计算「存在争议」，员工列表优先显示 disputed；历史版本不叠加当前申诉，ProfileClaim、版本快照和证据正文保持不变。

申诉原因及处理说明只向本人、原决定的 reviewer_user_id / acting_for_user_id 和本企业管理员开放，不沿用部门经理的普通可见范围。管理员维持决定或复制单项及证据引用到 correction 草稿，员工修改后走现有提交服务。处理与草稿、审计和通知在同一事务完成。申诉文本不写入证据或审计详情。

允许处理后再次申诉，同项仍最多一个 open 记录。管理员允许重新提交只生成草稿，不代表批准；新草稿照常适用企业审批规则。机器人不暴露该写工具，MCP 可以直接申诉。
