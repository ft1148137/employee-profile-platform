# ADR-0021：ChatGPT 订阅支持目录外模型 ID

状态：采用（NERE-113）；2026-11-05。

Pi 仍锁定 0.73.1，不通过升级依赖更新目录。仅 `openai-codex` 在目录未命中时，复用目录中 `gpt-5.4` 的协议、地址和兼容配置，替换模型 ID；ID 限定为 `[A-Za-z0-9._-]{1,100}`。其他目录提供方仍要求命中，自定义提供方保持原规则。

目录外模型启用 reasoning，允许 off、minimal、low、medium、high，保留模板的 minimal→low 兼容映射，暂不允许 xhigh。能力接口返回 `in_catalog: false`，不能把接受配置视为订阅有权调用该模型。默认新配置改为 `chatgpt/gpt-6.1-sol`、high，已有配置不迁移。

Codex turn 的地址必须等于目录地址，不接受客户端指定其他站点。模型 ID 不影响出网策略；凭据、刷新、只读开发授权、工具权限和证据协议均沿用原链路。未采用为全部提供方构造任意模型的方案，以免放宽现有边界。
