# ADR-0028：管理助手只读功能登记表

状态：接受（NERE-271）

管理功能数量超过 Pi 单轮工具上限。采用功能登记表，由 S4 将 `list_admin_functions(area)` 和异步的 `admin_read(db, principal, function, args)` 接进对话，保持 Pi 协议和工具上限不变。

数据库会话及 Principal 由服务端注入。只读入口先复用 `get_org_admin` 检查权限，再用禁止额外字段的 Pydantic 模型校验参数。功能处理函数复用网页服务；路由中的查询及连接测试移入原领域服务，不改变网页响应。IM 测试直接等待原异步服务，不另建同步实现。

结果放在 `data` 内，列表额外返回服务端生成的表格卡，最多 20 行，保留完整计数与页面路径。业务异常映射为固定中文错误，不把异常详情和参数回传给模型。登记表记录接口方法和路径；覆盖测试要求每个管理员接口恰好归入已登记、明确排除或后续任务之一。

画像读取仍调用 `read_profile` 和 `visible_employee`。按照 NERE-271 的澄清，只在返回结果的深拷贝中，把三类证据标题替换为「工作记录」「员工自述」「经理评价」；其余字段不变。代价是助手无法凭标题区分证据，但可以使用证据 ID，数据库、网页和证据可见性均不受影响。

本任务不执行配置变更，不新增依赖或数据库表。快照、影响范围和安全输入字段只声明元数据，由后续任务实现。
