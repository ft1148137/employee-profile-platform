# ADR-0033：管理助手的一次性账号输出

状态：接受（NERE-281）

批量停用按单份变更集汇总账号停用、人员离职和名单导入的离职人数；不同变更集分别确认，不跨变更集汇总。

账号、角色和争议操作复用手工页面的服务与当前管理员的 Principal。变更集保存账号状态、角色和争议快照用于过期检测；人员类操作标记 `undoable=false`，快照不再意味着允许撤销。中文标题在读取时由登记表填写，不保存进 items。

发放账号和重置密码的 handler 返回带类型标记的临时结果。`apply` 在内存中收集这些结果，所有业务写入、审计和完成提示成功提交后，通过 `ChangeSetApplied.one_time` 返回。高风险的第一次确认仅记录时间，不调用 handler、不生成密码。重复应用返回冲突。

临时结果不写入变更集、消息或审计，也不交给模型。账号表复用手工页面的 XLSX 导出函数，编码后通过同一个响应交付，不新增保存文件或再次下载的接口。apply 响应设置 `Cache-Control: no-store`；其余读取仍返回 `ChangeSetPublic`。

前端在操作函数返回前剥离 `one_time`，查询缓存和操作缓存只收到普通变更集。一次性结果只保存在卡片组件状态中，用于复制密码或下载账号表；离开页面后不可恢复。若应用成功但响应丢失，管理员需要重新起草重置密码或重新发放待登录账号，服务端不保存可取回的明文。
