# ADR 0054：离线排程评测的 SolverPort

## 背景

M10 需要验证多个项目同时争夺人手时，联合求解能否改善配齐率或总延期。规划已在 D-033 登记接入门槛。

## 决策

在 Planning 定义 `SolverPort.solve(roles) -> Solution`。输入按提交顺序排列，每项包含角色标识、Planning 快照和已先提交的前置角色标识。输出包含每个配齐角色的人员、投入比例、起止日期及未配齐的角色标识。各角色使用同一企业和统一的人员标识空间，数据由已有权限范围内的快照提供。

`RuleSolver` 逐角色复用现有模拟器，并把占用叠加到后续快照的周容量。CP-SAT 只作为评测脚本的实现，OR-Tools 只进入开发依赖组。生产 Planning 继续使用原有的模拟和确认入口。

## 评测结论

建议接入 CP-SAT。严格优于较好基线的争夺案例占 4/12，CP-SAT 硬约束违反数为 0，单案例耗时中位数 0.0521 秒。Reviewer 核对后决定 B2 是否放行。

[逐案例数据与 D-033 判定](../m10-solver-eval.md)

## NERE-839 生产接入

Reviewer 确认 D-033 三项均满足。修复后的报告中，CP-SAT 在 4/12 个争夺案例中胜出，14 案硬约束违反数为 0，耗时中位数为 0.0748 秒。

现有 Capacity 企业开关开启时，每次生成方案使用一个需求的授权快照调用 CP-SAT。这与 D-026 的权限边界一致。求解器最多使用 10 秒构建模型并求解，只有得到最优且通过校验的结果才保存「优化方案」。延期或分阶段的结果沿用相应的确认条件。经理仍须按方案答复，再由需求方确认承诺。超时或求解异常时仍返回已有的规则方案。
