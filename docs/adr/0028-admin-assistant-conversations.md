# ADR-0028：管理助手会话与共享对话准入

状态：接受（NERE-261）

管理员可能没有员工身份。管理助手以企业成员账号持有独立会话，不改变员工机器人和 IM 会话的员工归属。

管理助手会话通过企业与用户的复合外键关联企业成员，所有读写从服务端 Principal 校验企业、账号和管理员角色。其他成员及管理员访问不属于自己的会话返回 404。

两类会话复用消息加密、历史长度限制和 BotSetting 保留期。未开启保留时，闲置两小时的消息不可读取，新消息写入和定期清理均删除过期消息；开启保留时按天清理。消息不作为画像证据。

共用 begin_turn、企业数据库锁、额度暂停和起草优先逻辑。企业并发统计两张会话表的有效租约之和；每小时轮数分别按员工、管理员账号统计。释放租约仍核对租约时间，避免旧轮次释放接管轮次的名额。

本次只有无参数 get_today 工具，直接读取管理首页相同服务。链接卡由服务端生成，页面上下文与卡片地址使用固定枚举，人员详情页用固定页面标识。功能登记和后续工具接线按独立子 issue 交付。
