# ADR-0038：首次设置使用持久管理对话

状态：采纳（NERE-368）。

首次设置需要在模型可用前填写安全表单，并能在离开、刷新后继续。采用现有管理对话和加密消息表，新增可空的 purpose=setup；部分唯一索引确保同企业同管理员只有一条，并发创建使用数据库冲突处理。

预置消息不增加模型轮数。setup_checklist 只存类型，setup_form 只存步骤名称，状态始终读取现有设置服务；凭据继续使用现有安全表单，不进入消息和模型上下文。模型就绪后使用原有流式会话和确认卡。

首次设置未完成时保护对话消息的清理、列表和读取路径；附件原文、过期模型上下文和确认卡密钥继续按现有保留期处理。完成判断沿用现有必做步骤规则（暂不配置模型也算完成），完成后恢复普通消息保留期。

初始化成功和后续登录共用首页路由，先取得会话 ID 再打开助手。普通新对话保持空白页。迁移回退只丢失 purpose，已有对话和消息保留为普通会话。
