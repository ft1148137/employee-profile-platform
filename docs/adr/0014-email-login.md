# ADR-0014：邮箱登录和旧账号迁移

状态：采纳。依据：E16、NERE-84。

员工编号仍用于名单匹配，登录名改为邮箱；邮箱去掉首尾空格并转为小写。新管理员也必须提供邮箱，但无需关联员工。登录失败的账号和 IP 限流规则不变。

名单邮箱必填，预览与确认导入都校验。检查部署范围的账号邮箱和登录名占用，只返回本次名单行号，不披露其他企业的账号。重新导入在原事务中同步员工邮箱、账号邮箱和登录名，并留审计。共享账号和平台超管的登录名变更只能由部署者处理，避免本企业管理员影响其他企业。

迁移前将每个账号的登录名保存到 `legacy_username`。员工邮箱有效、关联关系没有歧义、邮箱没有重复或被其他账号占用时，改为邮箱登录；否则保留原登录名和密码。降级逐个恢复 `legacy_username` 后删列。迁移不删除账号、不重置密码，也不改证据。没有员工身份的既有管理员保留原登录名。

`uses_email_login` 是兼容入口的共同判断。账号页提示补邮箱，名单重新导入后即可转换。兼容代码带 `shortcut:`，所有企业补全邮箱后再移除。CLI 按账号邮箱重置密码；没有邮箱的旧管理员需由部署者补全邮箱后使用。

本次不新增依赖，不发送邮件，不验证邮箱归属，不引入 SSO。
