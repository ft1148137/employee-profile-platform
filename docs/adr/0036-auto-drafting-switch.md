# ADR-0036：企业自动起草使用单一总开关

状态：接受。依据：NERE-295 A5、NERE-308 及 2026-11-11 技术规划核定。

原有能力排除与部门子树关闭同时参与词典发布、机器人和起草范围计算，管理员无法从一个地方判断起草是否开启。M4.2 改用企业级 `drafting_setting.auto_draft_enabled`，缺行、全新企业和升级后的已有企业均为关闭。删除能力排除及部门关闭两列，员工本人的退出选择保留。

关闭时手工开始和词典重新起草返回同一条 422 中文业务提示；同步后的增量起草静默跳过。排队后的任务执行及模型返回时再次核对开关。打开后使用当前词典全部能力，为所有在职且未退出员工起草；打开动作本身不排队。所有入口仍复用现有起草服务，证据只追加、正式画像批准发布规则不变。

词典不再携带 `ai_inference` 或写起草设置。上传旧 YAML 字段或 XLSX 的「AI 起草」「允许 AI 推断」列时忽略旧值，预览显示警告。个人接口用 `org_disabled` 表达企业关闭状态；个人 `enabled` 仍只表达本人选择。管理助手 `set_auto_drafting` 沿用确认卡、审计和撤销机制。

迁移删除的分项值不会由 downgrade 恢复，降级仅重建空列表和 false；完整恢复依赖升级前备份。此决定取代 ADR-0013、ADR-0016 和 ADR-0034 中按能力或部门限制起草、词典与分项设置同步的约定，其他版本、证据引用和发布约定保留。
