# ADR-0007：数据集驱动的模拟 Jira

- 状态：接受
- 日期：2026-11-03
- 对应：NERE-53 / M2-S3

## 决策

模拟 Jira 使用独立 FastAPI 应用，代码放在 `backend/app/connectors/jira/mock.py`，复用后端镜像和现有依赖。它不连接业务数据库，不加载真实租户数据；每个 URL 前缀只访问对应的合成数据集，凭据通过环境变量设置。

开发 Compose 默认启动；演示安装通过 `deploy/compose.mock-jira.yml` 启动，普通生产安装不包含该服务。只在 Compose 网络内监听，不发布宿主机端口；健康检查无需业务凭据。

数据在应用创建时加载并按更新时间、issue key 排序。Cloud 使用 accountId 和 ADF，Data Center 使用账号哈希派生的稳定 key 和 wiki 文本，两者共享 issue key。模拟日期统一输出北京时间，JQL 无时区日期按 Asia/Shanghai 解释。仅实现子 issue 约定的查询子集，其他写法返回 400。

## 代价与边界

不引入另一个镜像或外部 Jira 测试账号。启动后修改文件需要重建应用；内存分页仅用于小型合成数据集。Cloud 的分页令牌是页偏移字符串，不模拟服务端游标快照；这里只验证客户端分页行为。未知账号保留源显示名，不推断邮箱。

模拟接口不能替代真实 Jira 的兼容性测试，不覆盖限流、权限配置、自定义字段或故障注入。
