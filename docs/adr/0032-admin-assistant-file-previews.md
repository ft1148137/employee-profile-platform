# ADR-0032：管理助手的文件预览与模型摘要

状态：已采纳（NERE-266）。

名单沿用 `create_import` 保存预览，变更集只引用 `import_id`、`base_revision`，不另存附件，也不增加迁移。`apply_import(commit=False)` 将名单、账号停用、审计和变更集状态交给同一事务提交或回滚。应用前以名单版本和导入状态的快照检查过期。名单导入不能撤销；纠正时重新上传完整名单。

登记表的动态风险函数接收服务端 Session、Principal 和已校验参数，由服务端读取预览中的离职人数；两人及以上走既有二次确认，不能由模型指定人数或风险。

逐行预览复用网页的结构和组件，作为加密的助手消息保存，遵循原会话归属和保留期，刷新后可以恢复。向模型组装历史时，在字符截断之前将文件预览替换为各类条数和最多 20 条错误的行号、原因。文件全文、逐行差异、姓名、邮箱、部门和列映射不会随文件预览进入模型历史。上传接口本身不调用模型。

本次只接受名单 Excel/CSV。批量画像、工作记录、能力词典以及需要的加密附件列由 NERE-280 接入同一上传卡与预览卡流程。
