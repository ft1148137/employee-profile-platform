# ADR-0030：管理助手的普通变更集

状态：接受（NERE-263）

管理助手只通过 `propose_changes` 起草配置改动。每项经登记表的输入模型校验，保存规范化参数、修改前快照、修改后值和影响范围。确认卡由服务端生成并与对话消息一起保存；模型只收到对比摘要，没有应用、放弃或撤销工具。

`admin_change_set` 使用企业与会话、企业与创建人、企业与原变更集的复合外键。所有接口按服务端 Principal 限定企业及创建人，其他管理员也返回 404。一份草稿最多 50 项，替换同会话草稿时增加 revision。

应用先锁企业行，再锁变更集行，与手工设置保存的企业锁保持一致。在同一锁内比较 revision 和所有当前快照，任一变化都标为 stale，要求重新预览。所有检查完成后调用原服务的 `commit=False` 路径，仅由变更集提交一次；处理函数或提交失败时全部回滚，持久化草稿保持不变。

审计由原业务服务追加。执行期间通过 `Session.info.audit_context` 注入助手、会话和变更集来源，并覆盖同名业务来源字段，结束后在 finally 清除。手工调用的默认提交行为和审计不变。

撤销通过反向变更集复用同一应用路径。当前值仍等于原修改后值时直接应用，否则保存新的反向草稿并要求确认。只有反向变更集成功应用后，原变更集才标为 undone；放弃或失败的反向草稿不会使原改动丢失可撤销状态。没有快照的动作不能撤销。

本次仅登记提醒设置。高风险或需要安全输入的登记项暂时拒绝；二次确认、密钥输入和相关列交给 NERE-274。其他业务登记与事务调整交给 NERE-275，页面草稿高亮交给 NERE-276。本次不新增依赖。
