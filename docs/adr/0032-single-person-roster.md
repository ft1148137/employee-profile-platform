# ADR-0032：人员变动复用全量名单

状态：已采纳。关联：NERE-265。

网页和管理助手的入职、调岗、离职先重建当前名单，再调用现有名单预览和应用服务。网页确认继续使用名单应用接口；助手通过外层事务调用两个服务，均传 `commit=False`。默认调用仍自行提交。

名单服务接受内部的 `ParsedRoster`，将其中的在职员工转换成 CSV 并交给原解析器，继续使用同一套必填、邮箱、工号、上级关系和行数限制。已离职行保留在预览记录的 JSON 中，以内部 `inactive` 标记跳过差异计算和应用；外部上传不能设置该标记，原来的完整名单恢复在职规则不变。不新增数据库列或迁移。

离职的上级从剩余员工的当前汇报关系中移除，旧关系由原名单服务关闭。未提供的调岗字段保持原值，显式传空的职位、上级可清空；因此变更集保存参数时保留字段是否提供的信息。未填写工号的既有员工继续遵守名单导入规则，不参与对比，须先通过名单完善资料再办理单人变动。

人员功能保留快照用于过期检测，并用 `undoable=False` 禁止撤销。中文标题按当前登记表生成，只存在于返回的卡片，不写入持久化改动项。沿用企业锁、租户 Principal、名单版本和审计来源，人员服务不写画像判断或证据。
