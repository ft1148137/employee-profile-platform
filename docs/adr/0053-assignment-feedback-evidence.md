# ADR-0053 分配完成后的工作反馈

NERE-837 实施 D-032、E45(7) 和 11 月 19 日的裁定。分配完成后，企业管理员或有员工管辖权的经理可以为在职员工写工作反馈。「部门内分配」和「借调请求」共用反馈表单，服务端按企业和员工管辖范围筛选已结束分配。需求方的详情和决策记录沿用原有投影。

写反馈时锁定分配，在同一事务中追加一条受限的 `manager_review` 证据、创建 `pending_owner` 画像请求并通知员工。两者的来源均为 `assignment_feedback`。分配编号保存在证据的 `source_ref`，反馈正文只存在于证据记录。证据记录保留原需求方的内部权限信息，用于限制无管辖权的需求方访问正文。按 E46 和 NERE-862，有 E8 管辖权的经理可以为管辖范围内的其他在职员工写反馈、读取受限正文，即使该经理同时代表需求方。每条分配最多有一条有效反馈，纠错沿用证据更正流程并保留权限信息。

已有判断的能力追加证据。新判断以角色的有效最低等级起草，未定级时由员工选择。员工过目、编辑和提交沿用现有请求流程。免经理确认的条目按企业策略发布为「暂定」，其余由现有路由的经理审批。画像版本保留受限证据引用。

找人检索使用已发布的能力判断。反馈证据从证据数、最近证据日期、相应筛选和同等级排序中排除。增量起草继续只查同步来源的请求。迁移扩大请求来源列及其检查约束。有工作反馈请求时，降级拒绝执行并保留数据。
