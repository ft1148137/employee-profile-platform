# ADR-0042：初始画像状态与直属上级摘要

状态：已采纳（NERE-487）

空画像和“已生成候选”的提示不能区分未接入、没有个人记录与起草后没有判断。原有直属上级查询还把上级本人套进员工范围，导致设置页漏掉已保存的上级。

初始画像状态由现有请求、有效工作证据、来源连接、发布版本和起草进度在查询中推导，不新增持久状态或迁移。“待本人过目”必须有初始请求及改动项；已处理的请求或已发布版本为“已处理”；无判断与等待起草分开。列表、详情、管理员进度共用此投影，界面共用中文名称。

直属上级查询对下属员工应用 Principal 的范围约束，并保留 org_id 和有效任职关系条件。允许返回的上级字段只有 ID 和姓名。上级本人不因此获得员工详情、画像、请求或证据的读取授权；组织架构图继续只引用图内可见的人。

代价：推导会增加相关子查询，但员工列表仍保持最多三次数据库查询。状态表示当前数据能证实的进度，不推测模型失败原因，也不更改起草、审批和证据协议。
