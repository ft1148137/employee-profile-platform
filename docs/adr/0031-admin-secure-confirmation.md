# ADR-0031：管理助手高风险确认与安全输入

状态：接受。关联 NERE-274，延续 ADR-0030。

高风险项由登记表按参数计算，关闭全部或任一能力类别的经理确认属于高风险。应用接口先校验版本和快照，再记录第一次确认；五分钟内第二次点击才执行。反向变更集重新计算风险，使用相同接口。更新草稿和安全输入都会重置第一次确认，避免确认内容被替换。

安全输入通过独立 HTTP 接口，仅创建人可写登记项允许的字段。草稿参数和前后对比不保存密钥字段；密钥只加密存入 `admin_change_set.secrets`，执行前合并并校验，响应固定为「已填写」。应用、丢弃、过期和修订时清空，处理函数仍负责使用原服务的凭据保护和审计规则。模型没有读取密钥的工具。

管理员对话在模型调用和消息写入前统一检测疑似密钥，命中则拒绝保存并提示安全输入。请求校验错误不回显原始输入。检测采用保守格式规则，不能保证识别所有厂商格式；新增支持的凭据格式时集中扩展检测函数。

不新增依赖，不改变证据和正式画像发布协议。
