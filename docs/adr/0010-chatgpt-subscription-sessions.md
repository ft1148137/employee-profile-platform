# ADR-0010：ChatGPT 订阅会话与开发登录隔离

状态：采纳（NERE-69）。

部署用的设备码登录由管理员发起，浏览器以单次、有间隔的查询完成授权。LiteLLM 的交互登录会阻塞主线程并打印验证码，不用于网页流程。依赖锁定的 1.106.6 内部方法，有签名测试约束升级。Responses 转接实际需要 litellm[mcp]，由锁文件固定其依赖版本。

令牌使用现有 Fernet 密钥加密存入企业模型设置。每次调用先用新数据库会话锁定该企业设置，再拿进程锁，临时写入私有目录的 0600 文件。SDK 在非主线程执行；刷新后的文件即使调用失败也保存回数据库，最后删除文件。断开仅清除本地保存的授权，OpenAI 没有对应的令牌吊销接口。

开发环境可显式只读挂载本机 Codex 单个登录文件。只提取访问令牌、ID 令牌、账号和过期时间，从不复制刷新令牌；剩余有效期不足一小时拒绝调用。生产环境配置此挂载路径时拒绝启动。该模式不把本机授权保存进数据库。

用量限制优先解析 Retry-After，再解析错误正文的 resets_in_seconds / resets_at；无法得知时估计三十分钟。5 小时/每周原因按 limit_window_minutes 的 300/10080 区分，其余归为请求频率限制。正文格式未获得稳定的服务端接口契约，升级时需复核，不能视为精确配额预测。
