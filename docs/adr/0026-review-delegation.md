# ADR-0026：限时代理审批

经理只能为本人设置同企业启用成员作为代理，不要求代理人有员工身份。
审批路由仍返回原经理，统一的 `can_review` 返回当前用户所代表的原审批人。
直属审批优先；代理只展开一层，不扩大日常员工和证据可见范围，不能自批。
读取例外仍只在请求待审批期间有效；决定保存实际用户与 `acting_for_user_id`。
设置、撤销和代理决定均审计。新通知发给原审批人与当时有效的代理人。

有效期采用含开始、不含结束的时段。撤销保留记录，历史决定不受撤销影响。
使用 PostgreSQL 自带的 `btree_gist` 扩展和排斥约束，保证并发写入也不能
为同企业同经理保存重叠的未撤销时段。比仅在应用层先查询再插入更可靠。
降级删除本表，保留可能被其他表使用的扩展；再次升级可重复使用。
不新增 Python 或前端依赖。扩展随 PostgreSQL 分发，采用 PostgreSQL License。

2026-11-11 补充（NERE-305）：凭待审批请求读取证据时，审批页与证据详情页都按同一次 review_access 结果展示关联判断。例外只覆盖该请求主体员工的判断及其证据，不扩大到同一证据关联的其他员工。请求已处理、代理到期或撤销后仍回到原有可见范围，restricted 正文沿用既有规则。
