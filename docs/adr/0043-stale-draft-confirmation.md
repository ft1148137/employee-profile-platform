# ADR-0043：旧初稿提交携带员工核对的正式画像版本

状态：接受（NERE-614，2026-11-15）

## 背景

ADR-0042 的初稿预览以当前正式画像作为修改前的值，但请求的 revision 不随经理直接修改正式画像变化。只校验请求 revision，会让没看过预览、或拿旧预览提交的员工请求在后台静默对齐。

## 决定

保留请求 revision 的语义。预览增加可空的 base_revision，表示员工看到的正式画像版本；网页、助手确认卡和 MCP 提交时原样回传。提交服务在既有组织、请求和员工锁内检查：初始草稿涉及生成后被直接修改的当前判断，且 base_revision 缺失或不匹配时，返回 409、stale_initial_draft、中文说明和能力列表，先于状态变更、证据追加、审计和通知。

网页收到冲突就加载最新预览；助手返回中文说明和新确认卡，必须由员工再次点击。卡片保留展示时的版本，不以点击时读到的版本代替。MCP 的异常转发沿用现有实现。

## 影响

不增加存储、迁移或依赖。旧客户端仍可提交没有这类冲突的草稿；冲突初稿必须先预览，再回传 base_revision。正式画像在预览后任何变更都会使这类初稿的确认失效，即使变更是另一项能力；这是可逆、保守的默认行为。base_revision 是并发确认标记，不证明人实际阅读，也不授予额外权限。
