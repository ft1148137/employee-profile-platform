这份名单包含 30 名完全虚构的员工，用于名单导入预览、设置向导和端到端测试。邮箱使用保留的 example.com 域名；请勿用于联系真实人员。

- `sample-30.csv` 为 UTF-8 带 BOM，Excel 可以直接打开；工号应保留为文本。
- 六列依次是工号、姓名、部门、职位、上级工号、邮箱。前三列必填，后三列可以留空；上级必须是名单中的工号。
- 部门用 `/` 分隔层级。研发中心和运营中心各有一个「质量组」，它们是不同部门。
- 除最高负责人外均有直属上级；恰有三人未填邮箱；包含复姓、英文名和扩展区汉字「𤭢」。

名单按全量导入，名单里没有的在职员工会被停用。请先核对预览，再确认导入。

空白模板由 `app.domains.org.roster.template` 的 `build_template_xlsx()` 和 `build_template_csv()` 生成。Excel 模板有两行示例和「填写说明」工作表；实际使用前请替换示例。
