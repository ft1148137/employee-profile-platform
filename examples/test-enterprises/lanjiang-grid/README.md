## 岚江省电力公司（模拟）/ lanjiang-grid

合成测试数据，**测试用，不自动导入**。本目录任何文件都不会被 seed 加载器读取，只用于 NERE-19 的系统测试与画像核对。企业、人员、邮箱、变电站名称和线路名称全部虚构，不对应任何真实单位或个人。

省级电网供电公司，本数据集只取生产与管理侧的 5 个部门和若干班组，不含营销、基建、物资等条线，也不含变电运维班（运维人员只作为工作许可人出现在来源数据里）。行业分类 GB/T 4754 门类 D「电力、热力、燃气及水生产和供应业」，小类 4420「电力供应」。

### 组织形态：直线职能制（line_functional）

中心（部）主任对本专业全面负责，是唯一的部门负责人；**班组长不是部门负责人**，班组长（变电检修一班、高压试验班、线路运维班、带电作业班）直接向中心主任汇报。安全监察部和人力资源部对各生产中心只有业务指导权，没有人事任免权，所以安全培训专责在人力资源部有第二汇报人但主岗仍在安全监察部。

跨中心专项有两个，都不改变汇报线：

### 职级与资质口径

- 技能岗：初级工 / 中级工 / 高级工 / 技师 / 高级技师；专业技术岗七级至十级；管理岗四级（中心、部主任）。
- 现行上岗资质以**特种作业操作证**（高压电工作业 / 低压电工作业 / 高处作业·登高架设作业）和年度**「三种人」资格**（工作票签发人 / 工作负责人 / 工作许可人）为准。
- LJ002 邵同安的 HR 档案里留着一张 2013 年就过期、从未换证的「电工进网作业许可证（高压类）」，作为**过期证书**类误导证据使用。本数据集不对该证书的现行制度状态作任何判断。
- 持证 ≠ 具备能力：能力词典里 `live_line_work`、`dispatch_operation`、`work_permit_management` 三项都在 `needs_support` 档明确写了「资质是前提，不等于已具备能力」。

### work_records.csv 列定义

UTF-8 无 BOM，逗号分隔，表头固定 12 列：

| 列名 | 含义 |
| --- | --- |
| `record_id` | 企业内唯一的记录编号，如 `GZP-0001`、`JX-0013`、`AK-0008` |
| `source` | 来源名，取 `enterprise.yaml` 中 `kind: work_records` 的来源：工作票系统 / 检修记录系统 / 安全培训考试系统 |

| `occurred_at` | 发生时间，ISO 8601 带 `+08:00` |
| `actor_account` | 来源系统里的执行人账号（可能是未登记账号，见 `personas.yaml` 的 `account_truth`） |
| `actor_name` | 来源系统里显示的名字（公用终端显示为「班组终端」） |
| `actor_role` | 该记录里的角色：工作负责人、发令人、配合人、消缺执行人、试验负责人、机巡作业人、记录录入人、缺陷登记人、分析人、考试组织人、考评组长、考评员、培训讲师、演练总指挥、检查人 |

| `project` | 专项代码 `YF2026` / `LJGG`，不属于专项的记录留空 |
| `title` | 记录标题，含虚构的变电站与线路名称 |
| `detail` | 一两句纯文本描述，不含任何真实信息 |
| `status` | 来源系统里的状态：已终结、已执行、已闭环、已归档、已上报、已转改造、已完成、已公布、已整改、已合规 |

### 刻意设计的「证据 — 真实能力」差距

`personas.yaml` 的 `ground_truth` 不导入系统，用来核对画像推断是否准确。差距是故意留的：

- **证据低于真实水平**：应岚舒（LJ006）独立出试验报告，但工作票负责人签的是班长，经理又答「需要协助」；柴满仓（LJ010）巡线近二十年，记录全是班长代录，他只出现在参与者里；卞㵘（LJ004）已能独立处理常规开关柜缺陷，但自述保守、经理答 not_sure。按记录条数排序会把这三个人排到最低。
- **证据高于真实水平**：郎亦川（LJ015）自述已能独立担任正值，实际仍需正值全程监护；邵同安（LJ002）名下的 SF6 微水检测实际由高压试验班完成，加上那张过期的进网许可证，容易高估他的试验能力；蔺长河（LJ009）是机巡成果的审核人，实际飞行是艾尼瓦尔做的。
- **真实具备但完全无记录**（系统应输出「未知」，不是「不会」）：邬守诚（LJ008）带电作业班出身、近五年无记录；乔叙白（LJ013）审定的运行方式报告是纸质签批；卓振邦（LJ017）的票面抽查结论只在会议纪要里；人力资源部四人（LJ021–LJ024）所在部门没有接入任何来源，其中 LJ024 殷竹筠在三个来源里都没有记录，也没有自述和经理评价。
- **记录与真实一致**（用来验证系统不会无故偏移）：傅延川（LJ003）、杜焕明（LJ011）、艾尼瓦尔·托合提（LJ012）的机巡、房楚瑜（LJ018）、滕绍钧（LJ019），以及柴满仓确实不会无人机巡检这一条。
