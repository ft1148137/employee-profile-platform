# templates

行业能力词典模板，企业可按版本配置词典。

新增能力模板的格式、目录登记、校验和必带测试见 [扩展开发指南](../docs/extending.md#3-能力模板)。扩展通过提 PR 交付。

- `capabilities/tech-rnd.zh-CN.yaml`：技术研发团队（M0 演示企业使用）。
- `capabilities/` 下其余 10 份：SaaS、AIoT、汽车零部件、商业银行、医院、管理咨询、建筑施工、连锁零售、电网、高校，来自 `examples/test-enterprises/`（NERE-19），可作为计划书 §6.1 的行业参考模板。
